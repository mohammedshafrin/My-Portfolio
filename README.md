# Mohammed Shafrin - Personal Portfolio 🚀

A modern, sleek, and fully responsive personal portfolio website built to showcase my web development skills, cybersecurity knowledge, and creative digital projects. 

![Portfolio Preview](./Profile%20Image/My%20image.jpg) **🔗 [Live Demo](https://mohammedshafrin.github.io/My-Portfolio/)**

## ✨ Features

- **Modern UI/UX:** A dark-themed, glassmorphism-inspired design with custom noise overlays and floating background elements.
- **Interactive Custom Cursor:** A bespoke, inverted-color custom cursor that reacts to hover states on interactive elements.
- **Dynamic Content:** - Typewriter effect for professional roles.
  - Smooth reveal-on-scroll animations using the Intersection Observer API.
  - Interactive certificate filtering system (Security, Development, Analytics, Networking).
- **Responsive Design:** A fluid layout with a custom mobile hamburger menu, ensuring perfect rendering across desktops, tablets, and mobile devices.
- **Contact Form Validation:** Client-side form validation with simulated asynchronous submission states.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup for accessibility and SEO.
- **CSS3:** Custom CSS variables, Flexbox/Grid layouts, keyframe animations, and media queries.
- **Vanilla JavaScript:** DOM manipulation, event handling, and custom interactivity without heavy frameworks.
- **Typography & Icons:** Google Fonts (Syne, JetBrains Mono) and FontAwesome.
